# 로컬 문서 정책

프로젝트 진행 문서는 Notion의 `마인크래프트 서버 구동기` 페이지를 기준으로 관리합니다.

- Notion 허브: https://app.notion.com/p/353892fb6fc081b993efc5363ed3f607
- Notion 문서 DB: `문서 관리`
- Notion 작업 보드: `작업 칸반`

## 로컬에 남기는 문서

로컬 문서는 코드 작업 중 즉시 필요한 자료만 유지합니다.

- `architecture/`: 코드와 함께 버전 관리해야 하는 프로토콜, 릴레이, P2P 위험 계약
- `usage/`: 로컬 실행, 테스트, 수동 검증에 필요한 최소 가이드

## Notion에서 관리하는 문서

다음 문서는 Notion으로 통합 관리합니다.

- 제품 기획서
- 마일스톤
- TODO와 칸반
- CEO/진행 보고서
- 디자인 결정 기록
- closed alpha 체크리스트
- 모드 정책
- 이슈 해결 기록

## 새 문서 작성 기준

- 새 계획, 보고, 의사결정, 이슈 기록은 Notion에 먼저 작성합니다.
- 코드와 함께 변경되어야 하는 계약이나 실행법만 로컬 문서로 둡니다.
- 로컬 문서가 Notion 문서와 충돌하면 Notion을 기준으로 보고, 로컬 문서는 최신 기준에 맞게 줄입니다.
